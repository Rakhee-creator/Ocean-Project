# 🌊 OceanProject

**OceanProject** Simple beginner level,Java-based console application that celebrates the beauty, depth, and serenity of the ocean. This is the first foundational version.

## Current Features 
- Simple Java console application
- Displays a welcome message and ocean-themed output
- Uses basic Java syntax: `main()` method, `System.out.println()`, and string formatting
- Structured for future expansion

## 🛠️ Tech Stack
- Java (JDK 17+)
- IntelliJ IDEA (or any preferred IDE)
